# Food Ordering System

Simple Java console-based group project.

Compile from the project root:

```bash
javac -d out src/main/java/model/*.java src/main/java/exceptions/*.java src/main/java/datastructures/*.java src/main/java/service/*.java src/main/java/util/*.java src/main/java/app/*.java
```

Run:

```bash
java -cp out app.Main
```

Requires a JDK.
